# Notebooks

* `01_quickstart.ipynb` — load the index, inspect code-switch detection, look inside one
  retrieval call, run a small ablation, generate a grounded answer, and run the learning
  statistics on any scores CSV.

Run `make all` (or at minimum `make data && make index`) before opening it.
Start Jupyter from the repository root so relative config paths resolve:

```bash
jupyter lab notebooks/01_quickstart.ipynb
```
