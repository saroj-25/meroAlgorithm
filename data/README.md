# data/

| Folder | Contents |
|---|---|
| `raw/` | Drop your own course material here (`.md`, `.txt`, `.pdf`, `.docx`), then run `python -m src.data.ingest --input data/raw`. |
| `processed/` | Generated by `make data`: `knowledge_base.jsonl`, `eval_queries.jsonl`, `lid_dataset.jsonl`, `study_scores.csv`, `satisfaction_responses.csv`, `interaction_logs.csv`, `topic_gains.csv`. |
| `external/` | Third-party corpora, if you add any (kept separate so licences stay traceable). |

Everything in `processed/` is regenerable and git-ignored: `make clean && make data`.

**The shipped corpus and study data are synthetic.** The paper's knowledge base is
instructor-authored material and its student data is human-subjects data; neither is
public. See `docs/findings.md` for exactly what was calibrated to what.
